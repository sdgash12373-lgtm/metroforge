# Metroforge：都市創造

<img src="public/logo.png" alt="Metroforge 商標" width="120">

一個可以在手機與電腦瀏覽器上玩的城市建造遊戲，靈感來自《Cities: Skylines》。
使用 TypeScript + Three.js，簡約低多邊形風格。

## v2.0.0 城市等級

- 城市等級：聚落 → 鄉村（1,000 人）→ 城鎮（1 萬人）→ 縣轄市（10 萬人）→ 直轄市（100 萬人）；人口、每月收入、每月結餘都達標後按「升級」
  | 等級 | 建議人口 | 每月收入 | 每月結餘 |
  | --- | --- | --- | --- |
  | 鄉村 | 1,000 | 300 萬 | +30 萬 |
  | 城鎮 | 10,000 | 3,500 萬 | +200 萬 |
  | 縣轄市 | 100,000 | 4 億 | +1,000 萬 |
  | 直轄市 | 1,000,000 | 40 億 | +5,000 萬 |
- 動態財政（每月）：收入＝稅收＋中央補助＋規費（車資、機場）＋其他（觀光）；結餘＝收入−營運支出（道路、運輸、公共建設、行政人事）−建設支出（近三天的平均）。等級越高補助越少、行政成本越高
- 縣轄市開放：道路升級（雙向單線道 / 雙線道 / 四線道，越寬車速上限越高、可並排行駛）、人行道與行道樹、天橋、綠化建設（綠建築、綠地廣場、生態公園，附近算有公園）
- 直轄市開放：辦公區長出 70–200 公尺的摩天大樓（相鄰兩格合併成更大的樓）、主題樂園、購物商城
- 「建設 → 拆除建設」：拆掉公共建設、綠化或地標，退還一半費用
- 行人沿人行道走動，依人口多寡、晝夜與天氣增減；天橋上也有人走
- 「🚗 巡查」：第一人稱開車，遵守紅綠燈、跟車；電腦 W 油門 / S 煞車 / A、D 選擇下個路口左右轉 / V 切換視角 / Esc 離開；手機用左下角虛擬搖桿

## v1.1.0 日夜與天氣

- 正常速度 20 分鐘過一天、快轉約 6.7 分鐘（每 0.5 秒一個模擬步驟，一天 2,400 步；城市成長與收支的實際速度不變）；預算面板與建設維護費改以「每小時」顯示
- 日夜循環：太陽依時間與季節移動，黃昏晚霞、夜晚月光；夜裡大樓窗戶亮燈、路燈照亮道路
- 天氣：晴 / 多雲 / 下雨 / 雷雨（閃電）/ 起霧 / 颱風 / 下雪，有雲、雨絲、雪花與霧；上方列顯示鏡頭所在處的天氣與氣溫
- 氣候依地形：高雄為亞熱帶（夏季午後雷雨、7–9 月颱風、冬季乾燥）；平地為溫帶四季（秋冬晨霧、冬天下雪）
- 同一張地圖內也有差異：山區氣溫較低（每 100 m 約降 0.65°C）、雨與霧較多；海邊早晨容易起霧、氣溫較溫和
- 天氣影響觀光：下雨觀光客減少，颱風期間觀光客停止來訪

## v1.0.0 Metroforge 正式登場

- 遊戲正式更名為 **Metroforge：都市創造**，換上新商標（瀏覽器分頁與手機主畫面圖示也一起更新）
- 「建設」工具（數字鍵 7）：公園、學校、警察局、消防局、醫院；點道路旁的空地興建，會自動貼齊道路，顯示服務範圍
- 城市地標（各限一座）：85大樓、市政府、龍虎塔、摩天輪、巨蛋；吸引觀光客，帶來觀光收入並提升商業與辦公需求
- 居民需求：上方「需求」面板顯示滿意度、各項公共服務涵蓋率與居民心聲；滿意度影響住宅需求，住宅升級需要附近有公共服務，高密住宅升到高等級需要學校
- 預算新增「觀光收入」與「公共服務」維護費
- 貨幣改為新台幣（NT$）；時間改用西元年/月/日 時:分:秒（從 2026/01/01 開始）
- 更新提醒：開始畫面顯示「更新內容」；進入遊戲後上方跑馬燈播放新版內容；遊戲開著時若網站發布新版本，跑馬燈會提醒重新整理
- 存檔 v6：記錄公共建設與地標

## 細節優化

- 新城市的地形參考高雄市：西南臨海（有沿海的山丘）、中間是平原與零星小山、東南有一條大河流向海，東北從丘陵一路爬升成高山
- 地面道路、軌道、分區與機場只能蓋在平坦的陸地上；水面要用高架跨過，山區用隧道穿過（舊存檔維持平地）
- 三條以上道路交會的路口自動設置紅綠燈，直行對向同一時相輪流放行（圓環除外）
- 電腦拉路時按滑鼠右鍵即可結束
- 運輸工具新增「拆除路線」：點地圖上的路線或車站選取，再點一次或按「確定拆除」；沒有其他路線使用的車站會一起移除
- 捷運站體縮小；選捷運工具時隱藏建築、樹木與車輛，道路變半透明，軌道不會被擋住
- 開始畫面：繼續遊戲、新遊戲（城市名稱、高雄或平地地形）、讀取存檔、設定（陰影、自動存檔間隔）
- 多存檔：6 個存檔欄位加 1 個自動存檔，有縮圖、人口、資金、天數；可改名、刪除、匯出 / 匯入 `.json` 換裝置；存在 IndexedDB，舊版的單一存檔會自動搬到「自動存檔」
- 遊戲中「選單」（或按 Esc）：存檔、讀取、設定、回到開始畫面
- 存檔 v5：記錄地形與城市名稱

## M4 捷運、火車、高鐵與機場

- 底部「運輸」工具列：公車 / 捷運 / 火車 / 高鐵 / 機場
- 捷運、火車、高鐵各有自己的軌道，用「軌道」拉線（直線或曲線，可選地面 / 高架 / 地下；捷運預設地下、高鐵預設高架）
- 「車站路線」：在軌道上依序點出車站，按「完成路線」開通；列車在兩端折返，車廂沿著軌道彎曲
- 地下捷運站：月台大廳在地下（地面會變透明），地面有兩個捷運出口；火車站有月台、雨棚與站房；高鐵站有大屋頂與玻璃大廳
- 每條路線都能自訂名稱與顏色；預算面板可分別調整公車、捷運、火車、高鐵票價與機票
- 住家與工作地點附近有車站的通勤者會選最方便的運具；火車與高鐵還有外地旅客
- 機場：雙跑道或四跑道，可旋轉方向；道路與軌道只能從地下穿過機場
- 航班：自訂航班名稱與機身顏色；飛機進場、降落、滑行到登機門、起飛，每班依人口載客收票
- 「命名」工具：替道路取路名（整條直行的路一起套用，沿路顯示），新增並命名區域（可調範圍與名稱顏色）
- 存檔 v4：軌道、車站、路線、機場、航班、路名與區域

## M3 公車與高架道路

- 道路工具可切換「地面 / 高架 / 地下」：高架離地 8 m，有橋墩與梁；地下道路深 8 m，拉地下道路時地面變透明，看得到隧道與預覽路徑
- 手機拉路：設好起點後，按住拖曳會顯示預覽路徑，放開完成；雙指移動地圖
- 不同高度的道路交叉不會形成路口；從地面道路接出會自動做成匝道或隧道入口（最大坡度 18%，至少 45 m）
- 高架造價為地面的 3 倍、地下 4 倍，兩側都不能分區
- 「圓環」工具：4 通或 6 通，車輛逆時針單向繞行；靠近路口或道路時會自動吸附（預覽圈變橘色），蓋好後接上原有道路
- 「公車」工具（在「運輸」裡）：依序點道路設站，點回第一站（或「完成路線」）開通環狀路線，每站 $300；可刪除單條路線或清除全部路線
- 公車依路線長度配車（每 500 m 一台），到站停靠、上下客；站牌顯示候車人數
- 住家與工作地點附近都有同一路線的站時，多數通勤者改搭公車，路上車輛減少
- 選取路線可改名稱與顏色（12 色或自選顏色）
- 預算面板可調公車票價 $0–5：票價越高收入越多，但搭車的人越少
- 預算加入公車票價收入與公車營運成本

## M2 交通與經濟

- 每條路雙向各一車道（靠右行駛），車輛會跟車、在路口等空位，塞車自然形成
- 市民從家通勤到商業/辦公/工業區，貨車從高速公路運貨到工業區（A* 尋路，會避開壅塞路段）
- 「交通」檢視：道路依壅塞程度顯示綠 → 黃 → 紅，並顯示車輛數與平均車速
- 分區必須有道路連到城外高速公路才會發展；塞車會拖慢建築升級
- 預算面板：住宅稅、商業稅、道路維護；稅率影響需求
- 建造模式：鎖住視角旋轉與傾斜，手機拉路不會被手勢轉動

## M1 道路與分區

- 直線與曲線道路（二次貝茲曲線），可連續拉路
- 道路交叉、接到既有道路時自動切成路口
- 道路兩側自動產生 8 m × 8 m 分區格子（4 格深，跟著彎道走）
- 低密/高密住宅、商業、辦公、工業五種分區
- 建築依 RCI 需求自動生長、升級
- 自動存檔（瀏覽器 localStorage）

## 開發

```bash
npm install
npm run dev      # 開發伺服器，手機可用同網段 IP 連線（加 --host）
npm test         # 模擬邏輯單元測試
npm run build    # 產出 dist/
```

## 程式架構

```
src/
  sim/        純邏輯，不依賴 Three.js（可放進 Web Worker、可單元測試）
    geometry.ts   向量、貝茲曲線、交點
    roads.ts      道路網：節點、路段、吸附、路口切割
    zoning.ts     分區格子產生、遮擋計算、塗抹
    city.ts       城市狀態、RCI 需求、建築生長、預算、存檔
    traffic.ts    車道、尋路、車輛跟車與壅塞
    signals.ts    路口紅綠燈的時相與燈號
    terrain.ts    地形（平地、高雄）：高度、水面、可建地
    transit.ts    公車站與車站、路線、配車與乘客（公車、捷運、火車、高鐵共用）
    rail.ts       捷運、火車、高鐵的軌道網與列車設定
    airport.ts    機場配置、航班狀態與飛機位置
    levels.ts     城市等級、升級條件與解鎖內容
    facilities.ts 公共建設、地標、綠化、天橋
  render/     Three.js 畫面
    world.ts      場景、燈光、樹、預覽
    terrainMesh.ts 地形網格、海面與山林
    signals.ts    紅綠燈
    roadMesh.ts   道路網格
    buildings.ts  分區格與建築（InstancedMesh）
    vehicles.ts   汽車、貨車、公車
    transit.ts    公車站亭與候車人潮
    railMesh.ts   軌道、枕木、高架橋與隧道口
    stations.ts   捷運站與出口、火車站、高鐵站
    trains.ts     捷運、火車、高鐵列車
    airport.ts    機場與飛機
    cameraRig.ts  城市建造用相機
    pedestrians.ts 人行道上的行人
  storage/    存檔欄位（IndexedDB）、匯出匯入、舊存檔搬移
  ui/         HUD、工具與輸入（滑鼠 + 觸控）、開始畫面與選單
```
