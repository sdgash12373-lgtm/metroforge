# 天際線 Skyline City

一個可以在手機與電腦瀏覽器上玩的城市建造遊戲，靈感來自《Cities: Skylines》。
使用 TypeScript + Three.js，簡約低多邊形風格。

## 目前進度：M4 捷運、火車、高鐵與機場

- 底部「運輸」工具列：公車 / 捷運 / 火車 / 高鐵 / 機場
- 捷運、火車、高鐵各有自己的軌道，用「軌道」拉線（直線或曲線，可選地面 / 高架 / 地下；捷運預設地下、高鐵預設高架）
- 「車站路線」：在軌道上依序點出車站，按「完成路線」開通；列車在兩端折返，車廂沿著軌道彎曲
- 地下捷運站：月台大廳在地下（地面會變透明），地面有兩個捷運出口；火車站有月台、雨棚與站房；高鐵站有大屋頂與玻璃大廳
- 每條路線都能自訂名稱與顏色；預算面板可分別調整公車、捷運、火車、高鐵票價與機票
- 住家與工作地點附近有車站的通勤者會選最方便的運具；火車與高鐵還有外地旅客
- 機場：雙跑道或四跑道，可旋轉方向；道路與軌道只能從地下穿過機場
- 航班：自訂航班名稱與機身顏色；飛機進場、降落、滑行到登機門、起飛，每班依人口載客收票
- 「命名」工具：替道路取路名（整條直行的路一起套用，沿路顯示），新增並命名區域（可調範圍與名稱顏色）
- 存檔 v4：軌道、車站、路線、機場、航班、路名與區域

## M3 公車與高架道路

- 道路工具可切換「地面 / 高架 / 地下」：高架離地 8 m，有橋墩與梁；地下道路深 8 m，拉地下道路時地面變透明，看得到隧道與預覽路徑
- 手機拉路：設好起點後，按住拖曳會顯示預覽路徑，放開完成；雙指移動地圖
- 不同高度的道路交叉不會形成路口；從地面道路接出會自動做成匝道或隧道入口（最大坡度 18%，至少 45 m）
- 高架造價為地面的 3 倍、地下 4 倍，兩側都不能分區
- 「圓環」工具：4 通或 6 通，車輛逆時針單向繞行；靠近路口或道路時會自動吸附（預覽圈變橘色），蓋好後接上原有道路
- 「公車」工具（在「運輸」裡）：依序點道路設站，點回第一站（或「完成路線」）開通環狀路線，每站 $300；可刪除單條路線或清除全部路線
- 公車依路線長度配車（每 500 m 一台），到站停靠、上下客；站牌顯示候車人數
- 住家與工作地點附近都有同一路線的站時，多數通勤者改搭公車，路上車輛減少
- 選取路線可改名稱與顏色（12 色或自選顏色）
- 預算面板可調公車票價 $0–5：票價越高收入越多，但搭車的人越少
- 預算加入公車票價收入與公車營運成本

## M2 交通與經濟

- 每條路雙向各一車道（靠右行駛），車輛會跟車、在路口等空位，塞車自然形成
- 市民從家通勤到商業/辦公/工業區，貨車從高速公路運貨到工業區（A* 尋路，會避開壅塞路段）
- 「交通」檢視：道路依壅塞程度顯示綠 → 黃 → 紅，並顯示車輛數與平均車速
- 分區必須有道路連到城外高速公路才會發展；塞車會拖慢建築升級
- 預算面板：住宅稅、商業稅、道路維護；稅率影響需求
- 建造模式：鎖住視角旋轉與傾斜，手機拉路不會被手勢轉動

## M1 道路與分區

- 直線與曲線道路（二次貝茲曲線），可連續拉路
- 道路交叉、接到既有道路時自動切成路口
- 道路兩側自動產生 8 m × 8 m 分區格子（4 格深，跟著彎道走）
- 低密/高密住宅、商業、辦公、工業五種分區
- 建築依 RCI 需求自動生長、升級
- 自動存檔（瀏覽器 localStorage）

## 操作

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 使用工具 | 左鍵點擊 | 單指點擊 |
| 移動地圖 | 拖曳、WASD / 方向鍵 | 單指拖曳（分區工具時用雙指） |
| 縮放 | 滾輪 | 雙指捏合 |
| 旋轉視角 | 右鍵拖曳、Q / E | 雙指旋轉 |
| 切換工具 | 數字鍵 1–7（2 = 道路、6 = 運輸、7 = 命名） | 底部工具列；「道路」「運輸」「命名」點進去再選 |
| 鎖住視角 | 「建造模式」 | 「建造模式」 |
| 暫停 | 空白鍵 | 上方按鈕 |
| 取消拉路 / 取消公車路線 | Esc | 「結束拉路」/「取消」 |

## 開發

```bash
npm install
npm run dev      # 開發伺服器，手機可用同網段 IP 連線（加 --host）
npm test         # 模擬邏輯單元測試
npm run build    # 產出 dist/
```

## 程式架構

```
src/
  sim/        純邏輯，不依賴 Three.js（可放進 Web Worker、可單元測試）
    geometry.ts   向量、貝茲曲線、交點
    roads.ts      道路網：節點、路段、吸附、路口切割
    zoning.ts     分區格子產生、遮擋計算、塗抹
    city.ts       城市狀態、RCI 需求、建築生長、預算、存檔
    traffic.ts    車道、尋路、車輛跟車與壅塞
    transit.ts    公車站與車站、路線、配車與乘客（公車、捷運、火車、高鐵共用）
    rail.ts       捷運、火車、高鐵的軌道網與列車設定
    airport.ts    機場配置、航班狀態與飛機位置
  render/     Three.js 畫面
    world.ts      場景、燈光、地面、樹、預覽
    roadMesh.ts   道路網格
    buildings.ts  分區格與建築（InstancedMesh）
    vehicles.ts   汽車、貨車、公車
    transit.ts    公車站亭與候車人潮
    railMesh.ts   軌道、枕木、高架橋與隧道口
    stations.ts   捷運站與出口、火車站、高鐵站
    trains.ts     捷運、火車、高鐵列車
    airport.ts    機場與飛機
    cameraRig.ts  城市建造用相機
  ui/         HUD、工具與輸入（滑鼠 + 觸控）
```
